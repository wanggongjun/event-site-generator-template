# 活动输入

正式活动提供 Word 通知、XLSX 和素材。Word 用于核对原文；event.xlsx 是唯一结构化编辑源。不得把生成后的 config.json 当成下一次内容源。

fictional-conference.xlsx 为虚构单类别示例；recovery-multi/event.xlsx 为虚构多类别示例，展示自定义类别 key 与实践子类型。均不对应真实机构、账号或接入资源。用 create_sample.py 创建新活动，换 slug 和内容，不使用这些示例中的日期/地址作为正式资料。

每场活动依次确认：正文差异、截止策略、容量策略、类别与材料要求、他山或独立接入、测试/正式域名及资源。凭据不入表。
