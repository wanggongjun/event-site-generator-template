## 飞书维护网站

同一 Base 新增五张以 kiz-ai-camp-2026· 开头的表，沿用 Base 会务管理员，不创建公开编辑权限。

- 网站设置：改活动名、日期、地点、主题颜色、页脚咨询信息；横幅和标志直接上传到图片列。支持 PNG/JPG/WebP，单张不超过10MB；标志推荐透明PNG。
- 页面栏目：改栏目名称、导航顺序、正文；可停用普通页面或新增 /p/英文名称 页面。正文支持 Markdown 标题、段落、列表、链接、表格，不接受 HTML。页面图片最多6张，展示在正文上方。首页的 {{培训日期}}、{{活动地点}}、{{园区地址}} 自动取网站设置。其他重复出现的事实请一并更新预览核对。
- 报名字段：可添加短文本、长文本、单选、多选、数字、日期问题，设置必填、停用和选项。新增行字段标识留空；选项每行一个。已发布问题不能更改类型，需停用旧题并新增。姓名、手机号、身份及单位专业等共享资料为固定信息；开票字段保持条件必填。原始列与历史报名快照保留，自定义答案显示在报名审核表“自定义报名信息”列。
- 网站发布：只保留一行。操作选择“生成预览”，等约30秒，打开预览链接核对各页和表单；确认后选“发布预览”。预览后继续编辑会阻止发布，须重新生成预览。不要连续更改操作，等待处理结果变成成功或报错再操作。
- 发布记录：记录版本号和发布时间。回滚时把版本号填入网站发布的“回滚到版本”，再选“回滚”；不填默认回滚上一版。回滚只改变官网，飞书编辑区保留草稿。

预览链接是仅供会务分享的只读链接，7天有效；不开放账号登录、上传或报名。发布操作仅在飞书授权编辑范围内触发，无公开发布接口。线上页面读取服务器已发布快照，不实时依赖飞书。当前版本、预览、发布历史和图片都保存在 recovery.sqlite 并随每日备份保存。切换版本使用SQLite事务；飞书短暂故障保持当前正式版本。

报名提交校验前端使用的表单版本；版本变更要求刷新核对，旧答案保存在原报名历史中。新增题使用飞书记录ID固定标识，改题目名称不会关联到另一道题。恢复已冻结的旧提交仍沿用其原版本，不将新问题要求套到旧提交上。

## 会务操作

本营在原论坛飞书Base下有独立的 kiz-ai-camp-2026报名审核 表。旧论坛表和报名记录不改动。

- 审核时填写“当前状态”：待审核、审核中、需补充材料、已通过、未通过。
- 同时把“审核对应版本”填成当前“资料版本”，避免旧审核覆盖学员更新。
- “公开意见”会展示给该学员；会务备注仅供内部工作人员。
- 财务单独填写“缴费状态”：待确认、已缴费、未缴费、已退款；“缴费公开说明”展示给该学员。
- 报名修改后重新待审核，保留历史。缴费状态独立，不因报名审核自动改变。
- 学员从“注册报名”或“个人中心”登录查询。证明材料仅本人及授权会务人员可查看。
- 系统保留表用于兼容模板数据模型，不开放投稿入口，不要向其中录入报名。

费用暂定所有身份100元（拟），会场为（暂无）。正式收款账户按用户确认采用Word中的账户。实际转账由学员完成，本站不代扣款、不伪造支付成功。缴费凭证发送至会务邮箱，财务核验后更新飞书。

线上报名于2026-11-21 00:00:00（Asia/Shanghai，即11月20日24:00）关闭。之后按网站说明现场报名；既有学员仍可登录查询。
