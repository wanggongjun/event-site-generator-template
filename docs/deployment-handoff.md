# 真实运行与交接清单

当前交付范围是模板、虚构实例和本地运行，不包含生产上线。以下每项单独决定和交接，不把秘密放进活动表。

1. 域名/DNS/TLS：活动使用哪个域名、DNS由谁管理、HTTPS在哪里终止；PUBLIC_ORIGIN必须与浏览器实际地址一致。
2. 托管/服务器：目标平台、地区、Node24运行支持、HTTP监听/反向代理、服务启停负责人。先保持单实例，除非真实负载证明需要扩容。
3. PostgreSQL：每个活动一份独立数据库、最小权限应用账号、存储/网络限制、连接秘密安全注入。已有云Postgres或独立服务器均使用同一pg代码路径；内嵌PG仅用于本地演示和测试。
4. 备份/恢复：数据库与私有附件在同一PG备份中；明确备份频率、保留天数、恢复负责人，并在预发布环境实际恢复演练。生成器不等于数据库备份。
5. 短信：沿用注册和重置用途；提供审核通过的签名/模板、地区、费用预算和账号权限。实际送达、频率、错误处理需要真实预发布验证；测试不发送真实短信。
6. 飞书：两个业务审核表、精确字段/状态、应用最小读写和附件权限、工作人员名单与私有资料访问。活动内容不从飞书回写。真实授权、表格读写和私有附件访问需要确认及验收。
7. 私有材料：明确投稿文件保留期限、可访问工作人员、内容扫描要求和删除流程。已提供基础真实格式/大小校验，不宣称是防病毒扫描。
8. 发布和监控：批准的部署方式、环境变量注入、错误日志、服务健康检查、容量提醒、同步失败可见性和回滚负责人。记录发布源版本、输入工作簿哈希、数据库备份点。
9. 所有权和费用：服务账号、域名、发短信费用、托管/数据库费用及维护人员。没有授权不创建账号、购买、开放权限或对外发布。

真实模式使用APP_MODE=real、HTTPS PUBLIC_ORIGIN、外部DATABASE_URL和真实适配器配置；禁止模拟接口/验证码。首次上线前至少复核注册/重置、两个独立流程、补料、终态纠错、录用资格、同人计数、私有附件越权、配置更新保留记录、真实飞书延迟/失败与备份恢复。

运行时秘密见template/backend/.env.example，仅安全注入服务环境。示例不会自动加载.env，也不包含生产值。尚未提供服务凭据时，结果必须写为“适配器已实现，模拟已测试，真实集成未验证”。
