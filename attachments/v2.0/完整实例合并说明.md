# 完整实例分卷

由于上传通道单次大小限制，原完整 ZIP 无损拆成四卷，没有重新压缩或改动内部内容。下载同目录四个 `磐石手册生成实例-v2.0.zip.part01` 至 `.part04` 文件和 `合并完整实例.py` 到同一文件夹，运行：

```sh
python 合并完整实例.py
```

脚本会检查 SHA256 后生成原名 ZIP。四卷缺一不可。原完整 ZIP 的 SHA256：

`ab0af59b56925a33e1704b03f741d9c8ab3bc2849b399222477fe7494ae5bbc0`

源码物料 ZIP 与离线预览 ZIP 仍可直接下载解压，不需要合并。
