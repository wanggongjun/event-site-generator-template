## 接入与运行

1. 读根SKILL.md，一次收齐活动内容、真实容量/窗口、独立数据库、HTTPS、短信配置、飞书目标链接/既有应用身份、建表资源授权及API/协作者权限；未知事实不编造
2. 按README建项目环境，校验并生成实例，npm ci、build与tests
3. 将凭据放部署Secret或被忽略的env。实例根运行 node --env-file=.env.production backend/feishu-init.js --plan
4. 确认plan目标和具体新增项后，以同一脚本 --apply --authorize-base=<plan appToken> 保存 .env.feishu.ids；已兼容可只读plan加 --output=.env.feishu.ids
5. 加载secret env与IDs env，运行backend/check.js；确认新库属于此活动后，backend/start.js做保留数据的加表/加列，再check
6. 用获授权预发布资源完成真实短信、飞书审核/补料/私有回复/故障恢复与HTTPS验收，再决定生产上线
